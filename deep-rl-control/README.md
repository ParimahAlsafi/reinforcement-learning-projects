# Deep Reinforcement Learning for Control

Implementation and evaluation of deep reinforcement learning algorithms for discrete and continuous control environments.

## Methods

- Double Deep Q-Network (DDQN) for MountainCar
- Proximal Policy Optimization (PPO) for Pendulum-v1
- Soft Actor-Critic (SAC) for Pendulum-v1

## Environments

- MountainCar
- Gymnasium MountainCar-v0
- Gymnasium Pendulum-v1

## Key Components

- Experience Replay
- Online and Target Networks
- Double Q-Learning
- Actor-Critic Architectures
- Generalized Advantage Estimation
- PPO Clipped Objective
- Twin Q-Networks
- Automatic Entropy Tuning
- Multi-seed Evaluation
- Policy Stability Analysis
