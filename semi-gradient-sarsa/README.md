# Semi-Gradient SARSA with Tile Coding — MountainCar

Implementation and evaluation of Semi-Gradient SARSA with tile coding for the MountainCar control problem.

## Methods
- Semi-Gradient SARSA
- Linear Function Approximation
- Tile Coding with Multiple Tilings
- Epsilon-Greedy Exploration
- Multi-run Evaluation
- Cost-to-Go Visualization
- Greedy Policy Evaluation

## Environments
- MountainCar
- Gymnasium MountainCar-v0
